## ✨ 核心功能

**六个 Tab**
- **概览** — 本周要点 TL;DR、核心 KPI、大额项目（单笔 ≥500 万）、趋势/类型/厂商三张图表、厂商战况榜 TOP10
- **招投标汇总** — 全量中标明细，支持按信创类 / 厂商 / 周次筛选、搜索、排序、CSV 导出
- **厂商工商信息** — 14 家重点厂商档案，13 家内嵌企查查核验数据
- **政策行业** — 监管政策与行业动态
- **历史归档** — 按周回溯，时间轴视图
- **近期动态** — 招采计划与舆情，聚焦未来节点并带倒计时

**数据分层与可读性**
- `tier()` 将每条中标分为 **S / A / B / C** 四层，C 类长尾默认折叠，默认排序「金额优先、无金额沉底」
- 「信息来源」三档诚实标注：绿点=已核验直达原文 / 灰点=平台署名未核验 / 灰点=原文未收录（点击检索）
- 中标方名称做归一化处理（`WINNER_CANON`），聚合与图表口径一致

**AI 顾问（qwen.html）**
- 浏览器直连阿里云 DashScope，基于站内真实数据回答竞争格局、客户优先级、信创趋势等问题
- 系统提示词内置硬约束：仅依据真实数据、无数据明说「数据未覆盖」、每条结论附溯源链接

## 🔒 数据原则

这个项目最在意的不是数量，是**能不能信**。三条铁律：

1. **宁可少收，绝不纳假数据** — 每条记录必须可核验；金额拿不准一律写「金额未披露」，严禁编造或估算
2. **金额三类口径，绝不留空** — `268万元`（已披露）/ `金额未披露`（候选人公示）/ `框架入围`（多家共享）
3. **来源可溯源** — 每条记录带 `source`（平台名）与 `sourceUrl`（公告原文深链）；拿不到真实链接就留空、由页面生成检索兜底

**收录范围**：① 全部银行类金融机构（国有 / 政策 / 股份 / 城商 / 农商 / 外资）的软件类中标；② 全部国产化 / 信创**软件**项目（改造、适配、替代、自主可控、国产数据库与中间件替换）；③ 凯美瑞德（KMRD）银行与金融机构中标全收。

**明确不收**：纯硬件采购（服务器 / 芯片 / 存储 / 终端 / 密码机 / 动环 / 负载均衡 / 服务器 OS / IT 基建维保），即使冠以「信创」名义。

## 🛠 技术架构

| 维度 | 选型 |
| --- | --- |
| 形态 | **单文件静态站** — 无框架、无构建、无后端 |
| 图表 | Chart.js v4，**本地自托管**（不依赖境外 CDN） |
| 数据 | 内联 JS 数组，改数组即更新；全站 KPI 与图表均脚本动态计算 |
| AI | 浏览器直连 DashScope OpenAI 兼容接口（CORS 已验证） |
| 部署 | 双发布：GitHub Pages + 腾讯云 CloudBase 国内镜像 |

**设计约束**
- 三个数据桶：`currentWeekBids`（本周）+ `archiveData`（历史）+ `liangruiBids`（专题，独立桶）
- `weekOptions` 单一数据源驱动归档、周下拉与趋势图 —— 新增归档周只需加一项
- 每周自动化**只改数据数组**后 push，不触碰任何 UI 代码
- `auditData()` 哨兵在启动时自检字段缺失、日期越界、重复记录
